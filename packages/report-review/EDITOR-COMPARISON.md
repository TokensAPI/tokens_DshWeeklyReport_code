# 编辑模式与数据流

工作台按模式选择编辑器，不再提供独立编辑器下拉框。Tiptap 独立编辑器及其适配实现已移除；BlockNote 内部依赖的 Tiptap/ProseMirror 仍保留。

| 模式 | 编辑器 | 预览 |
| --- | --- | --- |
| 可视化编辑 | BlockNote | 直接编辑排版后的正文 |
| Markdown 实时浏览 | CodeMirror | 右侧实时阅读预览 |
| PDF 实时浏览 | CodeMirror | 右侧已保存版本的 PDF |

各模式共用工作台的 Markdown 正文、自动保存、saveToken 冲突保护和确认发布流程。切换前不必等待自动保存，当前文字会传入下一个编辑器。可视化与源码之间切换会重置撤销历史；Markdown/PDF 之间切换保留 CodeMirror 实例和历史。

BlockNote 支持六级标题、段落、行内格式、链接、嵌套列表、任务、多段落引用、普通代码块、分隔线、简单表格及独立图片说明/地址。没有编辑的源片段复用原文，改动的块重新序列化为 Markdown。CodeMirror 直接编辑原文。

复杂表格、HTML、脚注等仍使用原文保留块，可进入 Markdown 实时浏览修改。图片上传及宿主资产预览尚未接入；内置示意图可离线显示，其他图片地址显示占位。

本地演示点击「新建完整演示周报」获得各类样例，已有草稿不会被覆盖。客户端回归覆盖可视化编辑、Markdown/PDF 模式切换、内容回写、只读、浮层、滚动和演示持久化。真实 DSH 输入法及长文性能仍需实际验收。
