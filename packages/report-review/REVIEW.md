# UI 变更审查

基线：远端 V1.1 `95d716b`。审查日期：2026-09-16。范围为本地主线相对基线的全部改动，包括源码、生成产物、依赖、测试和文档。

## 保留的必要改动

| 改动 | 保留原因 |
| --- | --- |
| 工作台布局、生成/编辑分步、模板选择 | 对应工作台 UI 优化，继续使用已有 Host 接口 |
| 原生侧栏与会话入口、shell 弹窗 | 避免弹窗随侧栏布局裁剪，复用宿主控件 |
| Markdown 高亮、双向同步阅读、PDF 分栏与导出 | 对应编辑与实时浏览需求，导出仍验证当前保存令牌 |
| 自动专注、不透明主题、单层焦点边框 | 对应已确认的交互与视觉要求 |
| Markdown/GFM、PDF 演示及浏览器测试依赖 | 有实际调用，不是运行时额外下载；许可证随包保留 |
| 统一根目录构建、宿主依赖声明和锁文件 | 保证市场安装的统一包能加载原生入口与新 UI |
| 业务保护与回归 | 保留冲突保护、身份确认、不可变版本、人工发布、只读核对 |

本地演示不是生产报告必需功能，但已作为现有体验能力提供；独立提交，明确标注模拟数据，不连接真实服务。未擅自移除已交付能力。

## 清理与修复

- 重写本地提交历史，移除早期界面和文档中的旧品牌文案；检查文字与生成产物中的 Unicode 转义。
- 恢复 `README-client.original.md` 原始内容，不覆盖交接历史说明；当前行为记录在根 README、功能说明和样式约定中。
- 原有客户端契约测试保留 `test/client.test.mjs` 路径，浏览器工作台测试单独命名。
- 移除仅供测试使用的备用入口组件，将启动外壳移入测试；清理未使用的样式和过时提交号说明。
- 编辑器不再因审阅操作的忙碌/只读切换而重建，保留撤销历史；切换报告时使用独立历史。回归验证了审阅后撤销和重做。
