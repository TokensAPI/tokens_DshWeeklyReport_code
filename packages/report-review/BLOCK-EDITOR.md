# 可视化编辑器试接入

2026-09-16。按 `design/周报插件-UI精修落地方案.md` 的方案 A，在现有工作台接入 BlockNote 0.54.2 Core / React / Mantine。进入报告默认显示可直接编辑的文档。

## 当前能力

- 标题（1–6 级）、段落、有序/无序/任务列表、粗体、斜体、删除线、行内代码和链接。
- 多段落引用、普通代码块、分隔线、简单表格及行列操作、独立图片的说明与地址编辑。
- 中文斜杠菜单、选区格式条、区块拖动手柄和删除、撤销/重做。
- 已确认稿及忙碌状态沿用原只读判断；复用自动保存、saveToken、人工修改归因、版本与发布接口。
- Markdown 源码入口与原阅读/PDF 分栏保留。同一时刻只有一个可写编辑器；切换引擎保留当前文字，但重置撤销历史。Markdown/PDF 模式之间切换保留 CodeMirror 实例；可视化编辑固定使用 BlockNote。

## Markdown 保真策略

`block-markdown.mjs` 按 Markdown AST 顶层节点记录原始切片、空白和 BlockNote 区块快照。没有编辑时返回原文；每次编辑复用未改变节点的原始切片，只序列化变动节点。列表作为一个顶层源片段处理，编辑列表可能归一化该列表的缩进、编号与标记。

带对齐信息或复杂结构的表格、复杂引用、带 metadata 的代码块、原始 HTML、脚注、引用式链接和特殊起始编号列表暂不开放可视化内部编辑，以原文保留块展示，并可切换源码修改。原始 HTML 不执行；独立图片可编辑说明与地址，内置演示图片支持离线预览，其他地址显示占位。上传、缩放和宿主资产预览尚未接入。

本地演示中的「新建完整演示周报」会新建含各类编辑样例的草稿，不覆盖既有草稿。样例包含嵌套列表、任务、六级标题、引用、代码、表格和图片；脚注保留为源码兼容示例。演示图片也进入阅读预览和演示 PDF。

转换失败时提供源码兼容入口。没有新增评论、AI 定点改稿、协作对象或后端存储；只使用基础包，没有引入 XL。

## 宿主兼容修复

首次接入后实际 DSH 报错 `Cannot read properties of undefined (reading 'S')`。读取本机安装包确认：DSH Web frontend 提供 React/React DOM 18.3.1，而原插件误打包了 React DOM 19.2.8，启动时访问 React 19 私有字段失败；Mantine 9 也要求 React 19.2。

修复：构建将 `react-dom`、`react-dom/client` 与 React 一并作为宿主外部模块，Mantine Core/Hooks 锁定到兼容 React 18 的 8.3.18；本地测试 React/React DOM 锁定 18.3.1。构建检查 esbuild 输入，禁止打入任何私有 React、React DOM 或 scheduler。`host-runtime.test.mjs` 通过宿主模块映射调用最终发布包的 factory，再真实挂载编辑器及菜单，避免只验证源码重打包的测试页。

当前 desktop Profile 的插件目录是指向 `dev` 的链接，因此重新构建已更新该 Profile 的插件产物。需要完全退出并重启 DSH 以清除已失败的页面模块状态；尚未代用户执行桌面重启。

## 正文滚动与浮层修复

可视化正文在画布内独立滚动。BlockNote 浮层挂在所属 dialog 内、滚动容器外，维持模态框的交互边界；格式条和斜杠菜单使用固定坐标定位。精简格式条取消横向 overflow 裁切，通用表单样式不再覆盖编辑器输入框，链接表单因此可完整显示。

工具条/区块菜单使用稳定的 React 组件引用，避免输入和保存状态刷新时重新挂载；Markdown 输出用按 ID 查找和块序列化缓存，隐藏的阅读预览不再随每次输入解析整篇正文。

新增 `editor-layout.test.mjs`：80 段长文的滚轮与滚动到底、链接表单命中测试及实际提交、斜杠菜单连续帧定位与保存状态刷新、滚动后跟随光标。宽屏浅色和 700px 窄屏深色均通过。测试没有替代真实 DSH 长文性能测量，尚不能给出宿主输入延迟数值。
