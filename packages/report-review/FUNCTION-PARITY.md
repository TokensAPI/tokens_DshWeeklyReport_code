# 功能一致性与演示模式

核查基线：远端 V1.1 `95d716b`（rebase 后的后端基线）。核查时间：2026-09-16。

## 真实模式

本次未修改 report-core、weekly-report-source、report-pdf、weknora-connector，以及 report-review 的 Host 代码与业务辅助模块。回归通过 Git 对照证明这些文件与基线一致。

| 原功能 | 当前入口 / 核查结果 |
| --- | --- |
| 列表、读稿、会话隔离 | 左侧档案；仍调用 list/get，报告绑定真实宿主会话 |
| 新建空白稿 | 生成页底部填写标题；create 的 title/markdown/assets 参数不变 |
| 生成及分析要求 | 单独生成页；variety/end/analysisPrompt/webSearchEnabled 与默认模板保留 |
| 模板读取、保存、删除 | 生成页；templateList/templateSave/templateDelete 保留 |
| 编辑、撤销、自动保存和重试 | 同一 CodeMirror 编辑器；650ms 自动保存、saveToken、脏稿及冲突保护保留 |
| Agent 更新与自动预览 | 原 5 秒读稿轮询、preview 回执与取消逻辑保留 |
| 真实 PDF | 原 Host preview 与 PDF 下载接口；验证 PDF 文件头、saveToken、digest 后显示同步 |
| 分栏预览与导出 | 「PDF 实时浏览」左侧继续编辑、右侧查看 PDF；「Markdown 实时浏览」右侧即时渲染 Markdown，工具栏可导出同步后的 PDF；进入任一浏览模式自动开启专注正文 |
| 版本与人工重点资料 | 右侧版本历史/重点人工信息；timeline/humanItems/saveHumanItems 保留 |
| 确认发布 | 已恢复原版 confirm → versions → publishPlan → publish → reconcile → get 顺序；人工点击二次确认后执行 |
| 新修订 | startRevision，确认稿只读语义保留 |
| 发布回执及只读核对 | publicationStatus/reconcile 保留，不自动重传 |

保留“仅确认版本”辅助入口与原版确认发布流程。真实数据源、知识库及模型端到端行为仍需安装环境验收。

样式与导航变化：移除产品品牌名称；生成和编辑各占一个页面；新建空白报告从原生 prompt 改为页内标题框；侧栏按钮按当前会话打开。生成页与编辑页来回切换不会销毁编辑器或替换正文，新生成的报告使用独立记录。

实时阅读预览支持标题、列表、引用、代码、GFM 表格和任务列表，直接使用当前输入，不等待保存。HTML 不执行，图片显示替代文字（图片版式以 PDF 为准）。阅读预览不承诺与 Host PDF 分页或排版完全相同。分栏在手机宽度改为上下排列。

Markdown 浏览按渲染块的源码行号双向同步滚动，段落之间插值，避免长表格与换行导致简单百分比同步偏移；输入和尺寸变化后重新对齐。PDF 仍由 Host 在保存后生成，内嵌浏览器 PDF 阅读器独立滚动。

评论核查：基线与当前客户端均没有选区评论、回复线程或评论持久化接口。annotations 是人工修改归因与重点信息筛选，不是评论；本轮未新增评论系统。

生成表单按基础参数、分析要求分组。模板选择使用主题化 combobox，显示模板摘要；方向键、Home/End、Enter/空格选择，Escape 关闭下拉且不会关闭工作台，Tab 离开。

## 演示模式

点击工作台顶部“体验演示数据”主动进入。页面始终显示演示标记；默认仍为真实模式，不因真实请求失败而悄悄回退到模拟数据。

- 固定行情、分析、两份历史材料样例；品种、日期和分析要求写入演示报告，不执行实际行情查询或 AI 推理。
- 独立 localStorage 键 `run19-weekly-demo-v1`，支持关闭重开、刷新恢复；与真实报告、Host 数据目录完全隔离。
- 支持创建/生成、模板、编辑/自动保存、人工信息选择、不可变确认版本、版本差异、开启新修订。
- 从当前演示正文生成可下载的真实 PDF：本机字体绘制为图片后排版，始终标注模拟数据；不代表生产 PDF 版式，也没有文本选择层。
- “模拟确认发布”只改变演示存档，模拟提交/解析状态，不调用任何外部 API；不伪装成实际知识库上传。
- 演示数据不自动迁移到真实模式；模拟流程用于 UI 体验，不等同于生产后端正确性验证。
